# Yumi OPIc — Survey Sprint

OPIc AL 준비를 위한 개인 서베이 집중 연습 앱입니다.

## 현재 범위

복잡해진 기존 문제은행을 걷어내고 아래 11개 서베이 토픽만 활성화했습니다.

- 혼자 아파트 거주
- 음악 듣기
- 해변
- 공원
- 콘서트
- 쇼핑
- 조깅
- 걷기
- 헬스
- 집에서 보내는 휴가
- 해외여행

활성 문제은행은 `src/data/survey-bank.ts` 한 파일입니다. 각 토픽은 8문항으로 통일했습니다.

- 묘사 2문항
- 루틴 1문항
- 최근·최초 경험 2문항
- 기억·문제 경험 1문항
- 비교·변화 1문항
- 이슈·관심사 1문항

총 88문항입니다.

## 연습 방식

### 서베이 집중 드릴

선택한 서베이 가운데 3개를 뽑아 아래 학습용 번호 구조로 연습합니다.

- 2, 5, 8형: 묘사
- 3형: 루틴
- 4, 6, 9형: 최근·최초 경험
- 7, 10형: 기억에 남는 경험
- 14형: 비교·변화
- 15형: 이슈·관심사

11~13번 롤플레이는 이번 리셋에서 의도적으로 제외했습니다. 이 번호 매핑은 훈련 편의를 위한 분류이며 실제 OPIc에서 모든 유형이 항상 같은 번호에 고정된다는 의미가 아닙니다.

### 주제별 6유형

한 토픽을 고르면 묘사, 루틴, 경험, 기억 경험, 비교, 이슈에서 하나씩 뽑아 6문항을 연습합니다.

### 랜덤 1문제

활성 서베이 88문항 중 하나를 뽑습니다.

## 문제 출처 원칙

`verified` 표시는 공개된 수험자 복원, OPIc 기출 정리 자료, 강의 자료에서 반복 확인되는 문형을 연습하기 좋게 다듬은 것입니다. 공식 OPIc 원문 인증을 의미하지 않습니다.

`adapted` 표시는 해당 토픽에서 직접 확인되는 복원이 부족하거나, 비교·이슈형 훈련을 위해 일반적인 OPIc 출제 형식에 맞춰 보완한 문항입니다.

리셋 시 참고한 공개 자료의 예:

- Korea Times / Hackers OPIc 공원·콘서트 공개 연습 문제
- OPIc 관련 공개 기출 정리 블로그의 집, 음악, 공원, 해변, 집휴가 질문 정리
- 공개 수험자 복원 질문 모음의 조깅, 걷기, 쇼핑, 해외여행 문형

이 저장소는 공식 OPIc 문제은행을 복제하거나 공식 출제 확률을 주장하지 않습니다.
