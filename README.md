# Yumi OPIc — 오픽 모의고사 셔플

서베이 주제 · 돌발 · 롤플레이 · 고난도 문항을 **실제 OPIc 콤보 구조 그대로** 섞어
매번 새로운 15문항 시험지를 만들어 주는 연습 도구입니다.
문제는 텍스트로 보고, 답변은 타이핑(또는 마이크)으로 작성하면 바로 채점됩니다.

## 시험지 구조

| 문항 | 유형 | 묶음 |
|---|---|---|
| 1 | 자기소개 | 기본 스킵 (옵션으로 켤 수 있음) |
| 2 / 3 / 4 | 묘사 → 활동 루틴 → 과거 경험 | 콤보 1 · 서베이 주제 A |
| 5 / 6 / 7 | 묘사 → 과거 경험 → 가장 기억에 남는 경험 | 콤보 2 · 서베이 주제 B |
| 8 / 9 / 10 | 묘사 → 과거 경험 → 가장 기억에 남는 경험 | 콤보 3 · 돌발 주제 |
| 11 / 12 / 13 | 질문하기 → 문제 해결 → 관련 경험 | 콤보 4 · 롤플레이 |
| 14 / 15 | 이슈 · 변화 → 비교 · 전망 | 콤보 5 · 고난도 |

콤보 1과 콤보 2는 항상 **서로 다른** 서베이 주제에서 뽑히고, 같은 주제 안에서
같은 문제가 두 번 나오지 않도록 막아 둡니다.

## 문제 은행

기존 문제은행 **75주제 540문항**에, 사용자가 제공한 파고다 OPIc 교재의 실전 기출 유형과
문제 세트 구성을 바탕으로 만든 **교재 기반 73주제 303문항**을 추가했습니다.
현재 총 **148주제 843문항**입니다.

문항마다 출처를 표시합니다.

| 표시 | 뜻 |
|---|---|
| **기출 복원** | 응시자들이 복원해 공개한 실제 출제 문항을 옮긴 것 |
| **형식 기반** | OPIc 형식·유형을 따라 만든 연습 문항 |
| **교재 기반** | 제공된 파고다 OPIc 교재의 실전 기출 유형·세트 구조를 바탕으로 문구를 재구성한 연습 문항 |

> OPIc 공식 문제은행은 ACTFL/크레듀가 공개하지 않습니다. 시중 교재의 "기출"도
> 응시 후기를 토대로 재구성한 복원본입니다. 따라서 앱에서는 출처를 과장하지 않고,
> 공개 복원본은 `verified`, 교재의 문제 구조를 바탕으로 재구성한 문항은 `adapted`로 구분합니다.

## 모드

- **실전 모의고사** — 2~15번 14문항을 콤보 구조대로 한 세트 생성
- **주제별 연습** — 주제 하나를 골라 그 주제의 문항만 5개 셔플
- **랜덤 1문제** — 전체 은행에서 아무 문제나 하나

## 채점 기준 (100점)

| 항목 | 배점 | 보는 것 |
|---|---|---|
| 분량 | 30 | 유형별 목표 단어 수 대비 실제 분량 |
| 유형 적합성 | 25 | 묘사=형용사·위치 표현, 루틴=빈도 표현, 경험=과거시제·시점 표현, 롤플레이=질문 개수·대안 제시, 고난도=비교·의견 표현 |
| 연결어 · 담화 표지 | 20 | because / actually / for example / that's why … 몇 종류를 썼는지 |
| 어휘 다양성 | 15 | 서로 다른 단어 비율 (길이 가중) |
| 문장 구조 | 10 | 평균 문장 길이와 복문 표현 사용 |

답변에 한국어가 섞이면 총점을 40% 깎습니다. 점수와 등급(NH~AL)은 **자체 추정치**로,
실제 OPIc 등급과는 다를 수 있습니다.

## 음성 기능 (무료)

유료 음성 API를 쓰지 않고 브라우저 내장 Web Speech API만 사용합니다.

- **문제 읽어주기** — `speechSynthesis`, 대부분의 브라우저에서 동작
- **마이크 받아쓰기** — `SpeechRecognition`, Chrome · Edge에서 동작

둘 다 선택 사항이라 타이핑만으로도 채점 결과는 동일합니다.

## 로컬 실행

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

Node 20 이상이 필요합니다.

## Vercel 배포

백엔드가 없고 모든 상태를 브라우저 `localStorage`에 저장하므로 별도 환경 변수
설정 없이 그대로 배포됩니다.

1. 이 저장소를 GitHub에 올립니다.
2. [vercel.com/new](https://vercel.com/new) 에서 저장소를 임포트합니다.
3. Framework Preset이 **Next.js** 로 잡히는지만 확인하고 Deploy를 누릅니다.
   (Build Command · Output Directory 모두 기본값 그대로 두면 됩니다.)

CLI로 배포하려면:

```bash
npx vercel        # 미리보기 배포
npx vercel --prod # 프로덕션 배포
```
