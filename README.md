# Yumi OPIc — 교재 SET 기반 모의고사

**질문 하나씩 무작위로 뽑지 않습니다. 교재에 실린 SET 전체를 뽑고, SET 안의 순서를 유지합니다.**

사용자가 제공한 **파고다 오픽의 신 OPIc IM2-AL** PDF를 기준으로 영어 질문과 `문제 세트 구성`을 대조했습니다. 교재는 2020년 개정판 / 2023년 7쇄이며, p.14에 명시된 기출 분석 범위는 **2020년 7월까지**입니다. 공식 문제은행이나 2026년 최신 기출을 검증한 자료라는 뜻은 아닙니다.

## 현재 활성 문제은행

| 항목 | 수량 |
|---|---:|
| 교재 일반 주제 Unit | 28개: 선택형 8 + 공통형 20 |
| 교재 롤플레이 Unit | 26개 |
| 영어 질문 레코드 | 359개: 일반 218 + 롤플레이 141 |
| 일반 3문항 SET | 84개 |
| 롤플레이 11→12→13 SET | 47개 |
| 고난도 14→15 SET | 27개 |
| 출제 가능한 완전한 SET | **158개** |
| 검토 후 제외한 SET | 3개 |

1번 자기소개는 별도 문항입니다. 같은 문구가 서로 다른 롤플레이 SET에 실린 경우 출처별 레코드로 보존합니다. 위 숫자는 서로 다른 영어 문장 수를 뜻하지 않습니다. 고난도는 일반 Unit의 별도 SET이며 주제 수에 중복 가산하지 않습니다.

기존 540문항과 이전 업데이트의 303개 재구성 문항은 소스 파일로 보존하지만 **활성 문제은행에서 제외**했습니다. `verified.ts`, `survey-topics.ts`, `surprise-topics.ts`, `roleplay-topics.ts`, `advanced-topics.ts`, `textbook-bank.ts`는 더 이상 `src/data/index.ts`에서 가져오지 않습니다. 이전의 843문항 합계와 현재 교재 전용 합계를 혼동하지 마세요.

## 시험지 생성

| 위치 | 생성 방법 |
|---|---|
| 1 | 자기소개. 기본 포함, 시작 화면에서 제외 가능 |
| 2–4 / 5–7 / 8–10 | 선택한 서로 다른 서베이 2주제 + 공통형 1주제의 **완전한 SET**을 뽑아 세 위치에 무작위 배치 |
| 11–13 | 한 롤플레이 SET의 Q11·Q12·Q13을 그대로 연결 |
| 14–15 | 한 고난도 SET의 두 질문을 원문 순서대로 연결 |

**서베이 2 + 공통형 1의 비율은 p.13의 샘플을 참고한 앱의 연습용 정책**입니다. 모든 실제 시험의 고정 구성이나 출제 확률이라고 주장하지 않습니다. 주제부터 균등 추첨하고 그 주제의 SET을 추첨하므로 SET이 많은 주제가 과도하게 자주 나오지 않습니다.

이전의 `2/5/8=묘사, 3=루틴, 6/9=과거, 14=이슈, 15=비교` 같은 고정 유형 배치는 제거했습니다. 예를 들어 음식점 p.95 SET 1은 묘사→묘사→과거 경험이며, 인터넷 p.195 SET 6은 우려 사항→연령별 이용 비교입니다. 집 p.50 SET 6의 '방금 언급한 문제 중 하나' 질문은 앞선 문제 설명과 떨어지지 않습니다.

같은 주제라도 서로 다른 롤플레이 상황의 11·12·13번을 섞지 않습니다. Q13의 질문이 단순 경험이나 과거/현재 비교를 요구하면 임의로 문제 해결 경험으로 바꾸지 않습니다. 예: 렌터카 p.398, 재활용 p.383.

서베이를 2개 미만 선택했거나 유효한 SET이 없으면 명시적인 안내를 표시합니다. 다른 주제에서 질문을 빌리거나 선택하지 않은 서베이를 몰래 추가하지 않습니다.

## 서베이 범위

기본 활성: **집 / 음악 / 쇼핑 / 집에서 보내는 휴가 / 해외여행**.

영화·TV·국내여행은 교재의 선택형 Unit이므로 추가 선택할 수 있지만 기본으로 켜지지 않습니다. 선택하지 않은 서베이 주제는 고난도 SET에도 들어가지 않습니다. 공통형과 롤플레이는 별도의 연습 풀입니다.

사용자의 다른 선택 항목인 **공원 / 해변 / 콘서트 / 조깅 / 걷기 / 헬스**에는 이 교재의 독립적인 일반문제 Unit/SET이 없습니다. 임의 변형을 '교재 원문'으로 표시하지 않습니다. 관련 음악·건강·지형 문항, 공연·헬스장 롤플레이는 별도로 존재합니다. 저장된 이전 설정의 미지원 ID는 제거/대체하지 않고 안내합니다.

## 연습 모드

- 전체 모의고사: 교재 SET 5개, 자기소개 포함 15문항. 연습을 마친 뒤 문항별 답변 돌아보기.
- SET별 연습: 목록에서 원하는 SET을 선택하고 원래의 2~3문항을 순서대로 연습. `/exam?mode=practice&set=<SET-ID>`.
- 랜덤 1문제: 앞 문항의 답변이 필요하지 않은 교재 독립 질문만 추첨. 롤플레이 묶음과 맥락 의존 질문은 제외.

기존 `?mode=practice&topic=...` 링크는 해당 교재 주제의 완전한 SET 하나를 선택합니다. `count=1` 등을 붙여도 SET을 자르지 않습니다.

## 출처와 데이터 구조

`src/data/textbook/general-{1..4}.json`, `roleplay-{1..2}.json`에 전사 데이터를 보관합니다. 영어 문구는 유지하고 공백과 줄바꿈을 정리했습니다. 교재의 한국어 문항 제목을 요약 필드로 사용합니다. 영어와 한국어 제목이 완전히 일치하지 않는 경우도 원문을 임의 수정하지 않습니다.

질문 튜플: `[페이지, 교재문항표시, 앱의유형태그, 영어, 교재한국어제목, 선행문항인덱스?]`

SET 튜플: `[교재SET번호, SET표페이지, general|roleplay|advanced, 질문인덱스목록, 검토메모?, 제외사유?]`

`catalog.ts`는 이를 안정적인 ID, `sourceRef`, `dependsOn`, `QuestionSet`으로 변환하고 무결성을 검사합니다. 문항의 출처 페이지와 SET 표의 출처 페이지는 서로 다를 수 있습니다. 페이지는 이 PDF의 1-based 페이지이며 인쇄 쪽수와 일치합니다. `Question.type`은 앱의 기능 분류이지 교재의 Int/Adv 등급표시가 아닙니다.

### 제외·보존한 원문 이상

| 위치 | 처리 |
|---|---|
| 영화 p.75 SET 3 | 3문항 SET의 첫 행에 Q14 출제 표시도 있어 충돌. 임의 해석하지 않고 제외 |
| 쇼핑 p.152 SET 5 | 마지막 행에 대응하는 별도 영어 질문을 pp.153–154에서 확인하지 못해 제외. 뜻이 좁은 '예상 밖 사건'으로 대체하지 않음 |
| 인터넷 p.195 SET 5 | '어제 온라인에서 한 일' 질문이 표에만 있고 대응 영어 질문이 없어 제외. 현재형 루틴으로 대체하지 않음 |
| 호텔 p.266 | Q1/Q3 번호 반복은 검토 메모로 남기고 표에 적힌 내용 순서를 유지 |
| 휴일 p.294 | SET 3이 두 번 등장. general/advanced로 ID를 구분하되 인쇄 번호는 유지 |

`excludedSets`와 SET 목록 화면에서도 제외 사유를 볼 수 있습니다. 새 자료로 보완할 때 출처를 추가하고 검토 후 활성화해야 합니다.

## 실행과 검증

```bash
npm ci
npm test             # 소스 카탈로그 + 생성기 회귀 테스트
npm run typecheck    # 전체 앱 TypeScript 검사
npm run build        # Next.js production build
npm run dev
```

Node 22를 CI에서 사용합니다. 테스트는 모든 158개 SET을 개별 검증하고, 5,000개 시드의 전체 모의고사 및 1,000개 독립문항 추첨을 검사합니다. 순서·상황·주제·선행문항·중복 ID·미지원 서베이·기존 문항 혼입·출제 도달 가능성·원문 표기 이상 보존을 확인합니다. 테스트가 통과해도 영어 원문이나 공식 출제 여부의 외부 검증을 뜻하지는 않습니다.

## 답변 돌아보기·음성·기록

브라우저 TTS/받아쓰기와 답변 입력을 사용할 수 있습니다. 연습을 마치면 작성한 답변, 작성 문항 수, 영어 단어 수, 소요 시간과 교재 문항·SET 출처를 확인합니다. 영어 단어 수는 알파벳으로 된 단어를 세며, 단어 안의 아포스트로피·하이픈은 같은 단어로 처리합니다. 한국어 등 다른 문자와 숫자는 집계하지 않습니다.

검증된 채점 기준과 등급 환산 근거가 없어 자동 점수·등급·평가 피드백은 제공하지 않습니다. 최근 기록에는 연습 일시·모드·작성 문항 수를 저장하며, 이전 버전에서 저장한 점수와 등급은 기록을 불러올 때 제거합니다.
