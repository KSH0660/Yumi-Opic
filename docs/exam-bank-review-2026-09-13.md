# 실전 모의고사 문제은행 출제 검토 — 2026-09-13

> 최초 작성은 수정 전 검토 기록이었습니다. 이후 ① 출처 우선순위 필터 해제, ② 실제 청취·지문
> 열기 이력에 따른 미출제 우선 출제, ③ 고정 세트의 구간 배치를 표시 번호 기준으로 변경,
> ④ 롤플레이 구간 보정을 적용했고 이 문서를 그 결과로 갱신했습니다.

현재 출제 대상 **230문항이 모두 실전 모의고사에 나옵니다.** 출제 규칙 때문에 후보에서 빠지는
문항은 없습니다. 남은 과제는 규칙이 아니라 **자료가 없는 구간**입니다.

검토 대상은 로컬 저장소의 현재 코드다. 기본 서베이 11개를 전부 선택한 조건을 사용했고,
실제 출제에는 명시적으로 제외된 3개를 뺀 8개가 적용된다. 아래 빈도는 사용자의 응시 이력이
아니라 실제 빌더를 호출한 시뮬레이션 결과다. 배포 사이트의 코드와 사용자 브라우저의 실제
응시 기록은 이번 검토에 포함하지 않았다.

## 문제은행 규모

| 구분 | 값 |
| --- | ---: |
| 전체 문항(자기소개 제외) | 263 |
| 걷기·콘서트·조깅 (명시적 제외) | 33 |
| **출제 대상** | **230** |
| 출제 대상의 고유 영문 지문 | 147종 |
| 출제 주제 | 서베이 8 + 돌발 7 |

20,000회 추첨에서 **한 번도 나오지 않은 문항은 0개**다. 이전 검토에서 지적한
`shopping-e2`·`gym-e2`의 출처 필터 제외는 해당 문항이 고정 세트 자료로 교체되고
`verified` 우선 필터가 제거되면서 함께 해소됐다.

## 해소된 출제 규칙 문제

이전 검토 이후 집·산업·재활용 고정 세트와 돌발 롤플레이가 추가되면서, 기존 출제 규칙에
막혀 **230문항 중 36문항(15.7%)이 전혀 나오지 않는** 상태가 있었다. 원인은 두 가지였다.

| 원인 | 막힌 문항 | 내용 |
| --- | ---: | --- |
| 구간별 유형 순서 강제 | 24 | 2~4번을 `묘사→습관→경험`, 5~7·8~10번을 `묘사→경험→기억`으로 고정하고 선언된 고정 세트까지 이 순서로 걸렀다. 집 COMBO 1·3·5는 중간에 `비교`가, 산업 COMBO 1~5는 두 번째에 `묘사`가 들어가 전부 탈락했다. 산업은 14·15번에서만 나왔다. |
| 롤플레이 구간 서베이 전용 | 12 | 11~13번 구간에 `surveyOnly: true`가 있었다. "돌발 뱅크에 롤플레이 문항이 없다"는 전제가 재활용·산업에 롤플레이 6문항씩 생기면서 깨졌다. |

현재 규칙은 다음과 같다.

- **고정 세트는 자료의 표시 번호로 구간을 정하고 원래 유형·순서를 보존한다.** 번호별 유형을
  강요하지 않으므로 집 COMBO 1의 `묘사→습관→비교`도 2~4번에 그대로 나온다. 5~7번과
  8~10번은 유형 구성이 같은 한 쌍이라 서로의 자리에 들어갈 수 있다.
- **롤플레이 구간은 서베이·돌발을 가리지 않되, 실제 롤플레이 문항을 선언한 주제만 채운다.**
  자료 순서 세트로는 11~13번에 들어갈 수 없다. 이 보정이 없으면 롤플레이 문항이 0개인 돌발
  5개가 11~13번을 차지해, 3,000회 중 835회(27.8%)가 안내문과 어긋났다.
- 다섯 구간 중 두 곳이 돌발이며, 배치 조합 10종이 모두 나온다.

## 반복 체감

출제 이력(`examExposure`)은 실제로 듣거나 지문을 연 문항만 기록하며, 문항 ID가 달라도
정규화된 영문 지문이 같으면 함께 센다. 준비 화면의 추첨은 기록하지 않는다.

| 지표 (3,000회 연속) | 이력 미반영 | 이력 반영 |
| --- | ---: | ---: |
| 직전 회차와 동일 지문이 하나 이상 겹친 비율 | 57.79% | **2.87%** |
| 회차 간 평균 중복 지문 수 | 1.78개 | **0.03개** |

이력을 반영하면 **18회차에 고유 지문 147종을 모두** 본다. 이전 검토의 동일 시뮬레이션에서는
120회차였다.

## 보강이 필요한 자료

### 1순위 — 구간을 아예 못 채우는 곳

해당 주제는 그 번호대에 영원히 나오지 않는다.

| 주제 | 없는 구간 | 보강할 유형 |
| --- | --- | --- |
| 병원·치과 | 11~13, 14~15 | 롤플레이 3종 + `comparison`, `issue` |
| 약속·예약 | 11~13, 14~15 | 롤플레이 3종 + `comparison`, `issue` |
| 미용실 | 11~13, 14~15 | 롤플레이 3종 + `comparison`, `issue` |
| 구직·진로 | 11~13 | 롤플레이 3종 |
| 직업·직장 | 11~13 | 롤플레이 3종 |

**롤플레이(`roleplay_ask` → `roleplay_problem` → `roleplay_experience`) 3문항 세트가 최우선**이다.
병원 예약 문의, 미용실 예약 변경, 면접 일정 조율처럼 실제 시험에 자주 나오는 소재이고,
현재 11~13번은 서베이 8개와 재활용·산업 10개 주제만 나눠 쓰고 있어 가장 얇다.

그다음이 병원·약속·미용실의 `comparison` + `issue` 2문항이다. 현재 14~15번은 서베이 8개와
재활용·산업·구직·직장만 채운다.

### 2순위 — 후보 세트가 1개뿐

그 주제가 해당 번호대에 오면 매번 같은 문제가 나온다.

- **음악 듣기·헬스·집에서 보내는 휴가**: 2~4, 11~13, 14~15 **셋 다** 1개
- **해변**: 11~13, 14~15 각 1개
- **해외여행**: 2~4, 14~15
- **공원·쇼핑·재활용·산업**: 2~4
- **구직·진로**(2~4, 5~7, 8~10, 14~15), **직업·직장**(2~4, 5~7, 8~10): 5~6문항이라 구조상 불가피

새 유형을 만들기보다 **기존 유형의 두 번째 콤보를 추가**하는 쪽이다. 예를 들어 음악에
`comparison`+`issue` 두 번째 세트, 헬스·휴가에 롤플레이 두 번째 세트를 넣는다.

### 3순위 — 같은 영문 지문의 중복

출제 이력은 문항 ID가 아니라 정규화된 영문 지문으로 묶이므로, 중복 지문을 가진 ID를 늘려도
체감 다양성은 늘지 않는다. 새 문항은 **기존 영문과 겹치지 않는 지문**이어야 효과가 있다.

| 주제 | 문항 → 고유 지문 | 중복 |
| --- | --- | ---: |
| 해변 | 23 → 10 | 13 |
| 쇼핑 | 29 → 16 | 13 |
| 혼자 아파트 거주 | 33 → 23 | 10 |
| 산업 & 취업 | 25 → 17 | 8 |
| 공원 | 19 → 12 | 7 |
| 재활용 | 19 → 12 | 7 |
| 음악 듣기 / 헬스 / 집에서 보내는 휴가 | 14 → 9 | 각 5 |
| 해외여행 | 17 → 12 | 5 |

## 확인 방법과 한계

- `npm test`: **238개 모두 통과**. `npm run typecheck` 통과. 테스트 통과는 현재 규칙대로
  동작한다는 의미이며, 문제은행의 모든 문항을 활용한다는 보장은 아니다.
- 실제 `buildFullExam`을 **20,000회** 호출해 도달 문항을 집계했다. 자기소개는 제외했고,
  기본 서베이 전체 선택과 시드별 Mulberry32 난수를 사용했다. 230문항이 모두 관측됐다.
- `completeQuestionSets`로 다섯 구간의 후보 세트를 열거해 선언된 고정 세트와 대조했다.
  어느 구간에도 들어가지 못하는 선언 세트는 0개다.
- 롤플레이 구간 위반은 1,000회 추첨에서 0회이며, 11~13번에 들어온 주제는 서베이 8개와
  재활용·산업뿐이다.
- 반복 체감 수치는 이력을 회차마다 누적해 다시 넘기는 방식으로 3,000회 연속 시뮬레이션한
  결과다. 실제 사용자는 문항을 열어야 기록되므로, 건너뛴 문항이 많으면 수치가 달라진다.
- 문제은행에 문항이 추가될 때 **명시적으로 제외한 문항 외에는 적어도 하나의 실전 세트에
  포함될 수 있는지** 확인하는 검증을 유지하면 같은 누락을 조기에 찾을 수 있다.
